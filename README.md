# Adobe-Network-Rule-Manager
Adobe Network Rule Manager is  a software disable inbound and outbound network

**To be honest, many people who use unofficial copies of software such as Adobe products often manually block the applications’ inbound and outbound network connections. To simplify this process, I developed an application that automates the setup with just a few clicks. It provides a faster and more convenient alternative for users who are tired of configuring firewall rules manually.**
