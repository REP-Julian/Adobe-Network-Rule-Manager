# Adobe-Network-Rule-Manager
Adobe Network Rule Manager is  a software disable inbound and outbound network

**To be honest, many users who download pirated Adobe software manually block Adobe applications through Windows Firewall by disabling both inbound and outbound connections. To make this process easier, I created an application that automates it with just a few clicks.**

**This tool is designed for convenience and efficiency, especially for users who are tired of manually configuring firewall rules. If you're concerned that it might be a virus, it is not. The application does not contain any harmful functionality and will not damage your system. It may trigger warnings because it is not digitally signed or officially registered with Microsoft, but that does not automatically mean it is malicious.**
